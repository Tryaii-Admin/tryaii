    1. [enablement] Add "cache_control": {"type": "ephemeral"} on the LAST
    static block (end of system prompt or last stable message). For >5-min
    gaps use {"type": "ephemeral", "ttl": "1h"} (2x write premium).
    2. [fix:timestamp-datetime] at system+3562 (98% in): Remove it, round it
    to a coarse bucket (day/hour), or move it into the final user message
    (after the cached prefix).
    3. [impact] Fixing the FIRST finding alone extends the stable prefix from
    ~1018 to ~1037 tok.
    4. [verify] After deploying, assert usage.cache_read_input_tokens (writes:
    usage.cache_creation_input_tokens) > 0 in responses. 0 across
    identical-prefix requests = a silent invalidator is still present.
    5. [ttl] 5 min (refreshed FREE on every hit) / 1h opt-in via ttl:'1h'
    6. [batch] STACKS with the Batch API 50%: cache read in a batch = 0.1x *
    0.5x = ~95% off
 Intel     :
      TTL: 5 min (refreshed FREE on every hit) / 1h opt-in via ttl:'1h'
      Read discount: 90% (0.1x base input)
      Write cost: write premium: 1.25x (5-min TTL) / 2x (1-hour TTL); no
      storage fee
      Verify via: usage.cache_read_input_tokens (writes:
      usage.cache_creation_input_tokens)
      ! Below the model's minimum the marked prefix SILENTLY won't cache
      (cache_creation_input_tokens: 0, no error).
      ! Model switch = cold cache (model-scoped). Toggling extended thinking
      invalidates system+messages (tools survive).
      ! Serialize tool JSON deterministically (sorted keys, frozen order) —
      non-deterministic serialization is a classic silent invalidator.
      ! Concurrency: entry readable only after the first response begins
      streaming — warm one, then fan out.
      ! Pre-warm with a max_tokens: 0 request to skip cold-write latency on
      the first real request.
      ! On Opus 5 / Opus 4.8 / Fable 5 / Mythos 5: append {"role": "system",
      ...} to messages for mid-conversation instructions instead of editing
      the top-level system prompt — preserves the cached prefix.
      ! No prompt_cache_key equivalent — routing affinity cannot be steered;
      identical prefixes are the only lever.
