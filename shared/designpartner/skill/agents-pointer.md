## tryaii design-partner program

This repo is set up for tryaii design-partner enrollment: a resumable
`tryaii designpartner` command (questionnaire → optional diagnose run →
tiered consent → submission; nothing is sent without an explicit
--confirm). The playbook lives in
`.claude/skills/tryaii-designpartner/SKILL.md` — follow it when asked to
enroll as a tryaii design partner. Start with:
`tryaii designpartner --json`.
